# AskMiao (AI ChatBot)

[Traditional Chinese](llms.txt) | [English](llms_en.txt)

> An enterprise-grade intelligent knowledge-base conversational system powered by Contextual Hybrid RAG (Retrieval-Augmented Generation) and Agentic Autonomous Research architectures.

## Key Architectural Invariants & Concepts

1. **Agentic RAG Pipeline**:
   - ReAct research pattern where the model dynamically calls internal knowledge search, live web search, or deep web scraping.
   - Every response provides structured `research_trace` (steps, tools, parameters, durations, summaries) and clickable `sources_detail`; `sources_detail` lists only the entries the answer cites as `[n]`.
   - Tool results are always marked as untrusted data with `<untrusted_tool_result>`; `web_fetch` may only read URLs that appear verbatim in the user's message or this question's tool results (further limited by `WEB_FETCH_ALLOWED_DOMAINS` and `BLOCK_WEB_TOOLS_AFTER_KB`).
2. **Reasoning Effort Multi-Tier Selection**:
   - Supports 5 depth tiers: `none`, `low`, `medium`, `high`, and `xhigh` forwarded to Azure OpenAI v1 / OpenAI reasoning models.
   - Enforces Microsoft Foundry tool-call compatibility rules.
3. **Contextual Hybrid Retrieval**:
   - FAISS dense vector search and Whoosh BM25 sparse keyword search always both run and are merged by rank with standard RRF (`RRF_K`), then re-ranked by a required Cross-Encoder.
   - `RERANK_RELEVANCE_THRESHOLD` applies directly to the reranker probability (exact URL, post ID, and date matches exempt); when nothing passes, the tool reports that the knowledge base has nothing relevant.
4. **System-Wide Security Redaction**:
   - Recursive object masking and regex-based string redaction. Passwords and bearer tokens MUST appear as `[REDACTED]` in logs.
5. **Tool Extensibility & MCP Integration**:
   - Custom HTTP API tools and OpenAPI imports live in `custom_api_tools`; MCP servers and their cached tools live in `mcp_servers`.
   - `ResearchToolRegistry.get_tool_definitions()` loads enabled external tools on every assembly, so changes apply without a backend restart.
   - MCP tools are named `mcp_<server_name>_<tool_name>`; `execute_tool` routes on that prefix to `McpManager.execute_mcp_tool`.
   - Every endpoint under `/api/api-tools` and `/api/mcp`, including reads, MUST depend on `get_current_admin_user`; the environment of an MCP `stdio` subprocess MUST be built by `build_stdio_env()`, never the whole `os.environ`.
6. **Outbound Safety: SSRF Guard & Error Codes**:
   - Every outbound request driven by user input (OpenAPI spec URLs, `web_fetch`, MCP HTTP transport, custom API tools) MUST pass `ssrf_protection.py` first; an httpx client that follows redirects MUST register the `reject_unsafe_request` request hook so every redirect is validated again.
   - Unexpected exceptions are converted by `error_response.py` into random error codes; exception text and stack traces MUST NOT reach clients or the SSE stream.
7. **SSE Contract**:
   - `POST /api/chat/send` responds with SSE, emitting `start` -> `step_start` / `step_end` -> `token` -> `sources` -> `done`, or `error` on failure.
8. **Modern Lightweight Stack**:
   - Zero-dependency local setup with SQLite (`DATABASE_URL` also supports PostgreSQL); caching and the token revocation list are in-process memory structures. React 19 + Vite 7 frontend built with Bun.
