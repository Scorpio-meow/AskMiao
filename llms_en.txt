# AskMiao

[繁體中文](llms.txt) | [English](llms_en.txt)

> An enterprise knowledge-base chat system that checks its own sources and cites them (version 4.0.0). The FastAPI backend answers with hybrid retrieval (FAISS + BM25 + Cross-Encoder) and a ReAct research agent, citing the chunks or web pages it used as `[n]`; the React frontend streams the research trace and citations over SSE.

This file is for AI agents: read "System constraints" before changing code, and run the checks under "Verification" afterwards.

## File map

### Retrieval and the research agent

- [backend/app/rag/contextual_rag.py](backend/app/rag/contextual_rag.py): the HybridContextualRAG facade; adding or deleting chunks, clearing and rebuilding indexes, and startup reconciliation all go through it
- [backend/app/rag/indices/chunk_store.py](backend/app/rag/indices/chunk_store.py): reads and writes `rag_chunks`, the single source of truth for chunks
- [backend/app/rag/indices/vector_store.py](backend/app/rag/indices/vector_store.py): FAISS `IndexIDMap2` (ids are chunk_ids) and the `.legacy.bak` / `.mismatch.bak` renames of old indexes
- [backend/app/rag/indices/bm25_store.py](backend/app/rag/indices/bm25_store.py): Whoosh BM25 (`doc_id` is the chunk_id) and the tokenizer signature
- [backend/app/rag/tokenizers.py](backend/app/rag/tokenizers.py): jieba tokenization and `TOKENIZER_RULES_VERSION`
- [backend/app/rag/retrievers/hybrid.py](backend/app/rag/retrievers/hybrid.py): RRF fusion, exact matches, reranking, and the relevance threshold
- [backend/app/rag/research_session.py](backend/app/rag/research_session.py): per-question citation numbers, `web_fetch` URL provenance, web tools disabled after knowledge-base reads, untrusted-data wrapping
- [backend/app/rag/agent.py](backend/app/rag/agent.py): the ResearchAgent's system prompt, tool loop, and streaming events
- [backend/app/rag/tools.py](backend/app/rag/tools.py): built-in tools plus registration and execution of custom API / MCP tools, `approval_requirement()`
- [backend/app/rag/tool_approval.py](backend/app/rag/tool_approval.py): `ToolApprovalBroker`, in-chat approval for tools with side effects (ADR-0006)
- [backend/app/rag/evaluator.py](backend/app/rag/evaluator.py) and [backend/scripts/evaluate_retrieval.py](backend/scripts/evaluate_retrieval.py): retrieval evaluation and relevance-threshold calibration
- [backend/config/domain_profile.json](backend/config/domain_profile.json): domain words, record date fields, and summary fallback rules, strictly validated by `app/core/domain_profile.py`

## System constraints

1. **chunk_id is the only key for chunks**: `rag_chunks`, FAISS, and BM25 are always matched by chunk_id. Add and delete chunks through the `HybridContextualRAG` methods, which update all three under `vector_store.lock`; searches and writes run in worker threads via `asyncio.to_thread`.
2. **Bump `TOKENIZER_RULES_VERSION` when tokenization rules change**: a signature mismatch triggers an automatic BM25 rebuild, and read-only evaluation refuses to run.
3. **New settings have no hard-coded defaults**: add new settings as required, put example values in `backend/.env.example`, and update `docs/configuration.md` (both languages), the README settings table, and the environment variable list under "Verification".
4. **Tool results are untrusted data**: wrap them with `ResearchSession.wrap_tool_output()` before they reach the model; when adding a built-in tool, decide in `ResearchSession.record_tool_output()` whether it gets citation numbers and counts as a URL source.
5. **Three limits on web tools**: `web_fetch` goes through `ResearchSession.refuse_tool_call()` (URL provenance, `BLOCK_WEB_TOOLS_AFTER_KB`), then `is_web_fetch_domain_allowed()` and SSRF validation.
6. **Validate outbound requests and pin the IP**: requests driven by user input go through `httpx.AsyncClient(transport=SSRFSafeTransport(<DnsPool>), follow_redirects=False)` with redirects followed by `send_following_redirects()` (redirect response bodies are never read), or through `safe_fetch_text()`; user-supplied URLs use `DnsPool.USER_URL` and admin-configured endpoints use `DnsPool.CONFIGURED_ENDPOINT`. Calling only `validate_url_ssrf()` and then connecting separately can be bypassed by DNS rebinding. SSRF rejection reasons go to the log only, and clients get an error code from `format_ssrf_rejection()`.
7. **Only error codes leave the server**: unexpected exceptions become codes through `log_and_get_error_id()` or `build_error_payload()`, for REST, SSE, and tool results alike; validation errors that only describe the user's input are returned verbatim as `SafeClientError`.
8. **Admin endpoints depend on `get_current_admin_user`**: every endpoint of `/api/documents`, `/api/admin`, `/api/api-tools`, and `/api/mcp`, reads included; `backend/tests/test_tool_admin_permissions.py` enumerates the tool routes to check this. Identity and permissions always come from the database account returned by `resolve_token_user()`, never from the token's `is_admin` or `role` claims.
9. **MCP subprocess environments come from `build_stdio_env()`**: only `INHERITED_ENV_VARS` plus the server's `env_vars`; each subprocess runs in a fresh empty temporary directory and in its own process group, and closing it terminates the whole tree.
10. **Sources list cited entries only**: `sources_detail` comes from `ResearchSession.cited_sources()`, driven by the `[n]` markers in the answer.
11. **SSE event contract**: `start` → `step_start` / (`approval_required` / `approval_resolved` when approval is needed) / `step_end` → `token` → `sources` → `done`, with `error` on exceptions. The backend `app/api/chat.py` and the frontend `useChat.ts` and `sse.ts` follow it, so change event names or fields in all three places.
12. **Keep the intro site in sync**: when changing `rag/research_session.py`, `rag/retrievers/hybrid.py`, `WEB_FETCH_ALLOWED_DOMAINS` in `rag/tools.py` and `core/config.py`, `core/ssrf_protection.py`, or `INHERITED_ENV_VARS` in `services/mcp_service.py`, update `site/index.html` and `site/main.js` too.
13. **Bilingual documentation**: README, CHANGELOG, `docs/`, and the ADRs all have `_en` versions; update both and record changes under `[Unreleased]` in `CHANGELOG.md`.
14. **Bump versions together**: `__version__` in `backend/app/__init__.py`, `version` in `frontend/package.json`, and `CHANGELOG.md`; new required settings or changes to API permissions or the index format are breaking and bump the major version.
15. **Taiwan Mandarin wording**: user-visible text uses Taiwan Traditional Chinese terms, such as 使用者名稱, 電子郵件, 權杖, and 字元.
16. **Tools with side effects need approval first**: a new kind of tool that calls out must offer a `requires_approval` flag reported by `ResearchToolRegistry.approval_requirement()`, and must not run without an approver (`approval_user_id` is `None`). When a table gains a column, add the column and its backfill SQL to `COLUMN_UPGRADES` in `database.py`.
17. **Resource limits live in `app/core/limits.py`**: add or adjust limits there and update the "Resource limits" section of `docs/configuration.md` (both languages); do not scatter magic numbers across modules. Document text extraction always takes an `ExtractionLimits`: `ADMIN_UPLOAD_EXTRACTION_LIMITS` for admin uploads and `CHAT_ATTACHMENT_EXTRACTION_LIMITS` for chat attachments.
18. **Tool credentials are always encrypted at rest**: `custom_api_tools.headers` and `auth_config` and `mcp_servers.env_vars` and `headers` are written with `tool_secrets.encrypt_json()` and read with `decrypt_json()`; admin API responses go through `mask()`, and updates go through `merge_masked()` so masked fields keep their stored value. When adding a column that holds credentials, add it to `ENCRYPTED_TOOL_SECRET_COLUMNS` in `database.py` as well.
19. **Token validity follows `users.tokens_valid_after`**: always change passwords through `crud_user.update_user_password()`, which sets the column to the current time so every earlier token becomes invalid, and always create accounts through `crud_user.create_user()`, which sets it to the creation time; `upgrade_schema()` backfills accounts whose value is NULL on every start.
20. **Pinned dependencies**: to add or upgrade a backend package, edit `backend/requirements.in` and run `uv pip compile requirements.in --universal --python-version 3.10 --generate-hashes -o requirements.txt` in `backend/`; never edit `requirements.txt` by hand. Update and commit the frontend's `package.json` and `bun.lock` together (`frozenLockfile = true`).
21. **Markdown always goes through `remarkGfmSafe`**: render Markdown such as model answers with `frontend/src/pages/Chat/remarkGfmSafe.ts`, never with `remark-gfm` directly; the latter's autolink transform takes time quadratic in length on a long run of dots, hyphens, or underscores, or on repeated `www.`. After upgrading remark-gfm, run `remarkGfmSafe.test.tsx`, which compares the output for ordinary content and checks the time taken on adversarial input.

## Verification

- **Backend tests**: run `python -m pytest` in `backend/`. The repository has no `backend/.env`, so pass the required settings as environment variables: `ENABLE_WEB_SEARCH=true`, `AGENT_MAX_TURNS=5`, `CONVERSATION_HISTORY_MESSAGES=6`, `ADMIN_API_KEY`, `DATABASE_URL` (SQLite; on Windows use the `sqlite:///C:/...` form), `RRF_K=60`, `RERANK_RELEVANCE_THRESHOLD=0.2`, `WEB_FETCH_ALLOWED_DOMAINS=*`, `BLOCK_WEB_TOOLS_AFTER_KB=true`, `DOMAIN_PROFILE_PATH=config/domain_profile.json`, `ALLOW_REGISTRATION=false`, `LOGIN_MAX_FAILURES_PER_ACCOUNT=5`, `LOGIN_MAX_FAILURES_PER_ADDRESS=20`, `LOGIN_FAILURE_WINDOW_SECONDS=900`, `LOGIN_LOCKOUT_SECONDS=900`, `HOST=127.0.0.1`, `RELOAD=false`, `COOKIE_SECURE=false`, `ENABLE_API_DOCS=false`, and a valid Fernet key as `TOOL_SECRETS_KEY` (generate one with `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`). Importing `jwt_auth.py` loads the RSA keys from `backend/keys/` (generating them when missing), so that directory must be writable. Delete SQLite test databases created by an older schema first, or they lack the new columns. Some tests load the real embedding and reranker models; on Windows accounts with non-ASCII user directories add `--basetemp=<ASCII path>`, or FAISS fails to write its files.
- **Frontend checks**: in `frontend/`, run `bun run test --run` (Vitest), `bun run lint` (JS / JSX only), and `bun x tsc --noEmit`.
- **Retrieval quality**: `python scripts/evaluate_retrieval.py --golden <golden set> --k 1 3 5 --relevance-thresholds 0.1 0.2 0.3` (read-only, safe to run alongside the backend).
