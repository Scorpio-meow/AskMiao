## Key Architectural Invariants & Concepts

1. **Agentic RAG Pipeline**:
   - ReAct research pattern where the model dynamically calls internal knowledge search, live web search, or deep web scraping.
   - Every response provides structured `research_trace` (steps, tools, parameters, durations, summaries) and clickable `sources_detail`.
2. **Reasoning Effort Multi-Tier Selection**:
   - Supports 5 depth tiers: `none`, `low`, `medium`, `high`, and `xhigh` forwarded to Azure OpenAI v1 / OpenAI reasoning models.
   - Enforces Microsoft Foundry tool-call compatibility rules.
3. **Contextual Hybrid Retrieval**:
   - FAISS dense vector search and Whoosh BM25 sparse keyword search combined and re-ranked via Cross-Encoder for high precision.
4. **System-Wide Security Redaction**:
   - Recursive object masking and regex-based string redaction. Passwords and bearer tokens MUST appear as `[REDACTED]` in logs.
5. **Modern Lightweight Stack**:
   - Zero-dependency local setup with built-in SQLite, React 19 + Vite 7 frontend built with Bun.
