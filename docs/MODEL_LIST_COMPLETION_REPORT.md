## 🚀 如何使用

### 基本使用
1. 打開聊天頁面
2. 在輸入框左側找到模型選擇器
3. 點擊下拉菜單查看所有模型
4. 選擇所需模型進行對話

### 手動刷新
1. 點擊模型選擇器右側的 🔄 圖標
2. 觀察載入狀態（旋轉圖標）
3. 查看右下角的成功通知

### 調整輪詢間隔
```bash
# 編輯 frontend/.env
echo "REACT_APP_MODEL_POLL_INTERVAL_MS=180000" >> frontend/.env

# 重啟前端
cd frontend
npm start
```

## ⚠️ 已知限制

1. **性能**: `/api/tags` 響應時間 2.32秒，略超 2秒目標
   - **原因**: ngrok 隧道延遲 + 遠端 API 調用
   - **影響**: 微小，已有載入狀態指示
   - **緩解**: 使用緩存機制減少實際請求

2. **詳細信息**: 依賴外部 API 提供
   - **影響**: 部分模型可能缺少詳細信息
   - **緩解**: 優雅降級，僅顯示模型名稱

3. **環境變數**: 需重啟服務才能生效
   - **影響**: 配置不夠靈活
   - **未來**: 考慮熱重載或動態配置
