# 模型列表功能更新 - 快速參考

## 🎯 新功能一覽

### 1️⃣ 手動刷新按鈕 🔄
在模型選擇器右側點擊刷新圖標，立即更新模型列表。

### 2️⃣ 載入狀態指示 ⏳
模型列表載入時，選擇器內會顯示旋轉的載入圖標。

### 3️⃣ Snackbar 通知 📢
成功/失敗訊息顯示在右下角，6秒後自動消失。

### 4️⃣ 可配置輪詢間隔 ⚙️
在 `frontend/.env` 設定 `REACT_APP_MODEL_POLL_INTERVAL_MS` 調整自動更新頻率。

### 5️⃣ 模型詳細信息 📊
下拉菜單中顯示模型家族、參數大小、量化級別等信息。

---

## 🔧 如何使用

### 手動刷新模型列表
```
1. 打開聊天頁面
2. 找到模型選擇器（輸入框左側）
3. 點擊選擇器右邊的刷新圖標 🔄
4. 等待載入完成（會顯示旋轉圖標）
5. 右下角彈出成功通知
```

### 調整自動更新頻率
編輯 `frontend/.env`:
```env
# 設定為 3 分鐘
REACT_APP_MODEL_POLL_INTERVAL_MS=180000
```

重啟前端服務:
```bash
cd frontend
npm start
```

### 查看模型詳細信息
```
1. 點擊模型選擇器
2. 在下拉菜單中查看每個模型
3. 第二行顯示: 家族 • 大小 • 量化級別
```

## ❓ 常見問題

**Q: 為什麼點擊刷新沒反應？**  
A: 可能正在載入中，等待旋轉圖標消失後再試。

**Q: 模型詳細信息為空？**  
A: 部分模型可能不提供詳細信息，這是正常的。

**Q: 輪詢間隔修改後沒生效？**  
A: 需要重啟前端服務（Ctrl+C 然後 npm start）。

**Q: Snackbar 訊息太快消失？**  
A: 可以在代碼中調整 `autoHideDuration` 參數。
